# 导航后台界面优化

用户要求按实现者审美优化 A 的后台页面，设计与实现方式由实现者决定。

## 方案

选择“后台框架 + 共享样式”：深蓝侧栏、浅灰画布、白色内容面板，使用现有 ng-zorro 组件和图标。只改配色不能解决布局与操作区问题；整体替换组件会扩大改动并增加功能回归风险。

## 范围

- 分组侧栏、品牌区、版本信息、清晰的页头与页面说明。
- 菜单和标题跟随 Angular 当前路由，兼容 Hash、查询参数和重定向。
- 桌面保留侧栏折叠偏好；手机默认收起，展开时覆盖内容，选择页面后关闭。
- 统一表格、表单、标签页、提示、按钮、焦点与保存条；限制到后台，不改变导航首页。
- 网站管理操作区、站点信息及登录 / 密码管理面板做必要视觉整理。
- 保留登录、权限判断、数据编辑、密码管理和所有现有菜单入口；不引入账号、统计仪表盘或新依赖。
- 使用现有浏览器测试验证导航、响应式侧栏和认证回归，视觉检查桌面与手机截图。
- 构建前初始化原始数据，避免触发信息抓取；完成后恢复原始数据文件。
